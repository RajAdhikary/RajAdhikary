# Hi, I'm Raj Adhikary

PhD candidate in Linguistics at the University of Florida. I work on ecolinguistics and endangered language documentation, focusing on Garhwali in the Mandal Valley, Uttarakhand: how ecological knowledge, vocabulary and narratives change across generations of speakers.

## Projects

- **[ELICIT](https://github.com/RajAdhikary/ELICIT)**: an offline tool for structured photo elicitation in language documentation fieldwork. Photo stimuli, standardized question sets, typed and audio responses, and CSV export for analysis.
